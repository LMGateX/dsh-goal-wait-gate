# dsh-goal-wait-gate

A DeepSeek Harness (DSH) plugin that withholds DSH's automatic goal continuation while the owning agent still has live background work (background jobs and subagent descendants).

## Agent skills

### Issue tracker

Issues and specs live in this repo's GitHub Issues, driven by the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context layout: `GLOSSARY.md` at the repo root plus decisions in `docs/adr/`. See `docs/agents/domain.md`.
